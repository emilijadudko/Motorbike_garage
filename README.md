# Motorbike Garage

This is a custom project to build a dream garage where I can pick and choose what motorcycles I wish to own.
The aim of this project is to create a program that will allow me to build my dream garage based on the various motorcycles that exist. Each Motorcycle will be listed under the category of minimum license required to own the bike.

This project will feature:
-motorbike specs
-images
-custom wishlist
-table of comparisons
-price of each
